## 🎯 Система работает так:

- 📍 Хранятся в [`data/public-marks.json`](data/public-marks.json)

- ⭐ Помечены звёздочкой "⭐ Ваша метка"
- 💾 Сохраняются локально в браузере
- 🔒 Видны только вам

## 📝 Формат метки

Каждая метка - это JSON объект:

```json
{
  "name": "Парк Победы",           // Название места
  "status": "новая",                // новая, в работе, выполнена
  "diff": 3,                        // Сложность 1-5
  "desc": "Куча мусора у входа",   // Описание
  "author": "Айгуль Сейткали",     // Автор
  "vol": 8,                         // Кол-во волонтёров
  "lat": 51.2390,                   // Широта (Google Maps)
  "lng": 51.3720,                   // Долгота (Google Maps)
  "before": "https://...",          // Фото ДО (или null)
  "after": "https://...",           // Фото ПОСЛЕ (или null)
  "donate": null,                   // Блок доната (или null)
  "chat": [],                       // Чат сообщений
  "custom": false                   // false = публичная
}
```

## 🔧 Как это работает внутри

1. **При загрузке страницы:**
   - JavaScript загружает метки из `data/public-marks.json` (fetch)
   - Добавляет личные метки из localStorage
   - Рисует все метки на карте

2. **Личные метки:**
   - Сохраняются в localStorage браузера
   - Остаются только у вас
   - Помечены ⭐ символом

3. **Общественные метки:**
   - Загружаются с GitHub
   - Видны всем
   - Нет звёздочки ⭐

## ❓ Часто задаваемые вопросы

**Q: Мои личные метки видны другим?**
A: Нет. Личные метки хранятся только в твоём браузере (localStorage). Чтобы сделать метку общественной, отредактируй `data/public-marks.json`.

**Q: Как найти координаты места?**
A: Открой Google Maps → Кликни правой кнопкой на место → Координаты в выпадающем меню.

**Q: Обновлены ли метки в реальном времени?**
A: Нет, нужно перезагрузить страницу (F5). Чтобы добавить синхронизацию реал-тайм, нужен сервер.

**Q: Где мне загружать фото?**
A: Используй свободные хостинги:
- https://imgur.com (бесплатно)
- https://imgbb.com (бесплатно)
- Яндекс.Карты (копируй ссылку на фото)

## 🛠️ Техническая информация

**Стек технологий:**
- Leaflet.js для карты
- OpenStreetMap для тайлов
- JSON для данных
- localStorage для личных меток

**Как загружаются метки:**
```javascript
// Из GitHub (public-marks.json)
fetch('data/public-marks.json')
  .then(r => r.json())
  .then(data => { /* добавляем метки на карту */ })

// Из браузера (localStorage)
var customMarks = JSON.parse(localStorage.getItem('custom_pts'))
```

## 💡 Лучшие практики

- Описывай в `desc` ЧТО загрязнено (мусор? листья? вода?)
