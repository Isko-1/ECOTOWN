СОЗДАНИЕ МЕТКИ:
  1. Нажми "＋ Отметить место"
  2. Кликни на карту
  3. Заполни форму
  4. Выбери сложность (если 4-5 → доступен блок доната)
  5. Нажми "✅ Добавить метку"
  → Метка создана с 0 волонтёров ✓

ДОБАВЛЕНИЕ ДОНАТА:
  1. При сложности 4-5 звёзд
  2. Нажми "☕ Добавить блок доната"
  3. Напиши текст (зачем нужны деньги)
  4. Номер: +77778597323 (по умолчанию)
  → Блок доната добавлен в карточку ✓

УДАЛЕНИЕ МЕТКИ:
  1. Открой свою метку (с ⭐)
  2. Нажми "🗑️ Удалить метку"
  3. Подтверди
  → Метка удалена ✓

УДАЛЕНИЕ СООБЩЕНИЯ:
  1. Наведи на своё сообщение в чате
  2. Нажми "✕"
  → Сообщение удалено ✓
