# ECOTOWN — Карта волонтёров уборки 🌍

Открытая платформа для добавления и отслеживания мест, нуждающихся в уборке. Метки видны всем пользователям!

## Как работает система

### 📍 Два типа меток:

1. **Общественные метки** — видны всем
   - Хранятся в `data/public-marks.json` 
   - Имеют чистый значок 📍
   - Могут быть добавлены через Pull Request

2. **Ваши личные метки** — только в вашем браузере
   - Хранятся в localStorage
   - Помечены звёздочкой ⭐
   - Создаются кнопкой "＋ Отметить место"

## 🚀 Как добавить общественную метку

### Способ 1: Через GitHub (рекомендуется)

1. Открой файл [`data/public-marks.json`](data/public-marks.json)
2. Нажми на карандаш (✏️) — "Edit this file"
3. Добавь новую метку в массив `marks`:

```json
{
  "name": "Название места",
  "status": "новая",
  "diff": 3,
  "desc": "Описание проблемы",
  "author": "Твоё имя",
  "vol": 1,
  "lat": 51.2390,
  "lng": 51.3720,
  "before": "https://url-фото-до.jpg",
  "after": null,
  "donate": null,
  "chat": [],
  "custom": false
}
```

4. Нажми **"Commit changes"** → **"Create a new branch and start a pull request"**
5. Описание PR: "Добавлена метка: [название]"

### Способ 2: Через командную строку

```bash
git clone https://github.com/Isko-1/ECOTOWN.git
cd ECOTOWN
# Отредактируй data/public-marks.json
git add data/public-marks.json
git commit -m "Добавлена метка: Название места"
git push origin main
```

## 📋 Формат метки

| Поле | Описание | Пример |
|------|---------|--------|
| `name` | Название места | "Парк Победы" |
| `status` | Статус | "новая", "в работе", "выполнена" |
| `diff` | Сложность 1-5 | 3 |
| `desc` | Описание | "Куча мусора у входа" |
| `author` | Автор метки | "Айгуль С." |
| `vol` | Кол-во волонтёров | 8 |
| `lat` | Широта | 51.2390 |
| `lng` | Долгота | 51.3720 |
| `before` | URL фото ДО | "https://..." или null |
| `after` | URL фото ПОСЛЕ | "https://..." или null |
| `donate` | Блок доната (опционально) | `{text: "...", phone: "+..."}` или null |
| `chat` | Чат сообщений | `[{n: "Имя", t: "Текст", w: "09:15"}]` |
| `custom` | Пользовательская? | `false` для публичных |

## 🎯 Как найти координаты места

1. Открой [Google Maps](https://maps.google.com)
2. Кликни правой кнопкой на место → "Что здесь?"
3. Координаты появятся сверху в поиске
4. Порядок: широта (lat), долгота (lng)
